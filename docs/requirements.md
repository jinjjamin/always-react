# 요구사항 (Requirements)

> **무엇을, 왜 만드는지** 정의하는 문서입니다. 기술적인 구현 방법은 `design.md`에 적습니다.
> 마지막 수정: 2026-11-24

---

## 1. 목표

- **문제**: 올웨이즈 회사 사이트(https://www.alwaysinc.co.kr/)가 jQuery·GSAP 기반 정적 HTML로 되어 있어 화면·데이터 관리와 재사용이 어렵다.
- **해결**: 같은 화면을 React + TypeScript 퍼블리싱 구조로 옮기고, 공통 컴포넌트·목업 데이터·IA·Guide로 관리한다.
- **성공 기준**: 원본 사이트의 메인(`/`)과 프로젝트(`/project`) 화면·문구·이미지·주요 인터랙션을 React로 구현하고, PC(1024px~)와 모바일(~1023px)에서 원본과 같은 레이아웃으로 보인다.

## 2. 범위

### 포함 (이번에 만드는 것)
- 메인(`/`): Business 4개 섹션(스크롤 모션), Contact(주소·연락처·지도), 오른쪽 하단 섹션 표시, 모바일 전체메뉴
- 프로젝트(`/project`): 비주얼(슬로건 타이핑·마우스 그라데이션·always brief 링크), 포트폴리오 카드 10개와 상세 레이어, 전체 프로젝트 이력(10개씩 더보기), Footer, Contact 레이어
- 커서 포인트, 스크롤 등장 모션
- `/Ia`, `/Guide` 관리 화면

### 제외 (이번에 안 만드는 것)
- 실제 API 연동 (원본 `/public/getMain.ax` 응답을 목업 데이터로 변환해 사용)
- 카카오맵 API (원본 주석에 있던 지도 이미지 + 카카오맵 링크로 대체)
- 원본의 섹션 자동 스냅 스크롤(스크롤 진행 80~90%에서 다음 섹션으로 강제 이동)
- 원본의 레이어 열림 시 커서 확대 전환 효과, Contact 제목 타이핑 효과

## 3. 사용자 스토리

### US-01. 회사 소개 보기 (메인)
**방문자로서**, 올웨이즈가 어떤 일을 하는지 알기 위해, 첫 화면에서 핵심 사업과 대표 프로젝트를 보고 싶다.

- [x] WHEN 메인에 접속하면 THEN 헤더와 첫 섹션 문구가 아래에서 위로 올라오며 나타난다
- [x] WHEN 스크롤하면 THEN 섹션별 배경 오브젝트가 움직이고 프로젝트 카드가 위로 올라오며, 오른쪽 하단에 현재 섹션 이름이 표시된다
- [x] WHEN GNB의 Business·Contact를 클릭하면 THEN 해당 섹션으로 부드럽게 이동하고, Project는 새 창으로 열린다
- [x] WHEN 화면 너비가 1023px 이하이면 THEN GNB 대신 햄버거 버튼이 보이고 전체메뉴 레이어가 열린다

### US-02. 프로젝트 둘러보기
**방문자로서**, 올웨이즈의 작업물을 확인하기 위해, 포트폴리오와 전체 프로젝트 이력을 보고 싶다.

- [x] WHEN 포트폴리오 카드를 클릭하면 THEN 상세 이미지 레이어가 열리고 ESC·닫기 버튼으로 닫힌다
- [x] WHEN Load more를 클릭하면 THEN 로딩 표시 후 이력이 10개씩 추가되고, 모두 보이면 버튼이 사라진다
- [x] WHEN 헤더 메뉴 버튼이나 Footer의 Contact Us를 클릭하면 THEN Contact 레이어가 열린다

## 5. 비기능 요구사항

- **반응형**: 원본 기준 모바일(~1023px), 태블릿(1024~1280px), 데스크톱(1281px~)
- **브라우저**: 최신 Chrome, Safari, Edge, Samsung Browser
- **접근성**: 이미지 `alt` 필수, 버튼과 링크는 키보드로 접근 가능, 레이어는 ESC로 닫힘
- **성능**: 원본 이미지를 WebP로 변환하고 표시 크기에 맞게 줄여 사용 (29.3MB → 6.6MB), 웹폰트는 KS X 1001 서브셋 사용 (6.1MB → 1.46MB)
